Quattestor

Lapisan atestasi tahan-kuantum untuk withdrawal lintas chain — wallet apa pun jadi rentan Shor's algorithm sejak transaksi keluar pertama; Quattestor menambahkan gerbang tanda tangan ganda (classical + ML-DSA) sebelum dana bisa ditarik, di EVM maupun non-EVM, tanpa mengubah logic inti per chain.

Video demo akan ditampilkan di sini

Verifikasi langsung — isAttested(actionHash)

Baca langsung dari kontrak Verifier.sol yang live di testnet, lewat RPC publik (bukan NOWNodes — API key tidak pernah dikirim ke browser). Ganti actionHash untuk coba sendiri; nilai default di bawah adalah actionHash nyata dari transaksi atestasi sungguhan.
