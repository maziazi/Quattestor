Quattestor uattestor

The moment a wallet sends its first transaction, it's exposed to Shor's algorithm. Quattestor closes that gap by gating every withdrawal behind a second, quantum-resistant signature (ML-DSA). It works across EVM and non-EVM chains, with zero changes to each chain's core logic.

Verify it yourself

This reads attestation state straight from the live contract or program on each chain: Ethereum and Base through Verifier.sol's isAttested(), Solana through its on-chain attestation account, Cardano through its attestation NFT's mint history (eUTXO burns the token on withdrawal, so history rather than current existence is the honest check). Everything goes through public RPC endpoints, never NOWNodes, so no API key ever touches this page. Switch networks to try each chain.
